# HabitTracker — трекер привычек для macOS + Telegram-бот

Два связанных проекта в этом репозитории:

- **`HabitTracker/`** — нативное macOS-приложение на SwiftUI. Вкладка «Мои привычки» — личный локальный список с отметками и сериями (streak). Вкладка «Дашборд» — рейтинг участников по восьми базовым показателям (SAT, MP3, SLEEP, DIET, BOOK, BOOK PRO, RNK, Shield), которые они вносят через Telegram-бота, в трёх форматах: день / неделя / месяц.
- **`server/`** — Node.js-сервер: Telegram-бот, через который участники вводят свои показатели, плюс HTTP API, которое читает Mac-приложение. Подробности и деплой — в [`server/README.md`](server/README.md).

Код Mac-приложения:

```

HabitTracker/

  Assets.xcassets/           — иконка приложения и цвет акцента
  Models/
    Habit.swift               — модель одной привычки (локальный список)
    HabitStore.swift          — хранилище локальных привычек: загрузка/сохранение
    DashboardModels.swift     — модели данных дашборда, приходящих с сервера
    DashboardService.swift    — загрузка снимка и истории дашборда с сервера по HTTP
  Views/
    RootView.swift            — вкладки «Мои привычки» / «Дашборд»
    ContentView.swift         — экран локальных привычек
    HabitRowView.swift        — строка одной привычки
    AddHabitView.swift        — окно добавления новой привычки
    DashboardView.swift       — переключатель периодов (день/неделя/месяц)
    SettingsView.swift        — настройка адреса сервера и API-токена
    Dashboard/
      DailyRankingView.swift    — дневной рейтинг: компактный список
```

## Важно: где это можно запустить

Эта сессия работает в облачном Linux-окружении — здесь **нет macOS и Xcode**, поэтому я не могу собрать и протестировать это приложение сам. Собрать и запустить его нужно **на вашем Mac**. Зато теперь в репозитории есть готовый файл проекта `HabitTracker.xcodeproj` — создавать проект вручную через мастер Xcode больше не нужно (это было источником прошлых ошибок вроде «Multiple commands produce» и «does not conform to protocol»).

## Шаг 1. Установите Xcode

1. Откройте **App Store** на Mac.
2. Найдите **Xcode**, нажмите «Загрузить» (бесплатно, но весит несколько ГБ — установка может занять время).
3. После установки один раз откройте Xcode, чтобы он доустановил компоненты командной строки.

## Шаг 2. Скачайте код на Mac

```bash
git clone <ссылка на ваш репозиторий>
cd app
git checkout claude/macos-app-development-azxeq5
git pull
```

Если у вас уже есть склонированная папка с прошлой попытки — не создавайте новый проект в Xcode заново, просто обновите её командой `git pull` в терминале внутри этой папки.

## Шаг 3. Откройте проект

В Finder зайдите в папку `app`, дважды кликните по **`HabitTracker.xcodeproj`** — откроется Xcode с уже готовой структурой (файлы `Models`, `Views` и точка входа уже на месте, ничего добавлять руками не нужно).

Если до этого вы уже создавали свой пустой проект в Xcode («Untitled Project» / «MyApp» из скриншота с ошибкой) — его можно закрыть и удалить (Xcode → File → Close, затем удалить папку проекта в Finder). Он был лишним и вызывал ошибки.

## Шаг 4. Запустите

Нажмите **▶ (Run)** или `Cmd+R`. Через несколько секунд откроется окно приложения с двумя вкладками:

- **«Мои привычки»** — работает сразу, без сервера, данные хранятся только на этом Mac.
- **«Дашборд»** — покажет данные участников из Telegram-бота, но только после того, как вы запустите и настроите сервер (см. [`server/README.md`](server/README.md)) и впишете его адрес и токен в настройках вкладки (значок шестерёнки).

## Как продолжать «вайбкодить»

Дальше работа строится так: вы описываете, что хотите изменить или добавить, а я пишу код и кладу файлы сюда же, в ветку `claude/macos-app-development-azxeq5`. Вам останется подтянуть изменения (`git pull`) и нажать Run в Xcode.

Идеи для следующих шагов:
- Иконка приложения и красивый значок в Dock
- Виджет со статистикой на сегодня
- Уведомления-напоминания в течение дня
- Календарь-«тепловая карта» выполнения по месяцам
- Синхронизация между устройствами через iCloud
