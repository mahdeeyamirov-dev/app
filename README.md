# HabitTracker — трекер привычек для macOS + Telegram-бот

Два связанных проекта в этом репозитории:

- **`HabitTracker/`** — нативное macOS-приложение на SwiftUI. Вкладка «Мои привычки» — личный локальный список с отметками и сериями (streak). Вкладка «Дашборд» — сводная таблица по всем участникам, которые вводят данные через Telegram-бота.
- **`server/`** — Node.js-сервер: Telegram-бот, через который участники отмечают свои привычки, плюс HTTP API, которое читает Mac-приложение. Подробности и деплой — в [`server/README.md`](server/README.md).

Код Mac-приложения лежит в папке `HabitTracker/`:

```
HabitTracker/
  HabitTrackerApp.swift      — точка входа приложения
  Models/
    Habit.swift               — модель одной привычки (локальный список)
    HabitStore.swift          — хранилище локальных привычек: загрузка/сохранение
    DashboardModels.swift     — модели данных, приходящих с сервера
    DashboardService.swift    — загрузка дашборда с сервера по HTTP
  Views/
    RootView.swift            — вкладки «Мои привычки» / «Дашборд»
    ContentView.swift         — экран локальных привычек
    HabitRowView.swift        — строка одной привычки
    AddHabitView.swift        — окно добавления новой привычки
    DashboardView.swift       — экран сводной таблицы участников
    SettingsView.swift        — настройка адреса сервера и API-токена
```

## Важно: где это можно запустить

Эта сессия работает в облачном Linux-окружении — здесь **нет macOS и Xcode**, поэтому я не могу собрать и протестировать это приложение сам. Код написан по всем правилам SwiftUI и должен заработать, но собрать и запустить его нужно **на вашем Mac**.

## Шаг 1. Установите Xcode

1. Откройте **App Store** на Mac.
2. Найдите **Xcode**, нажмите «Загрузить» (бесплатно, но весит несколько ГБ — установка может занять время).
3. После установки один раз откройте Xcode, чтобы он доустановил компоненты командной строки.

## Шаг 2. Скачайте код на Mac

Если репозиторий уже на GitHub — просто склонируйте его и переключитесь на нужную ветку:

```bash
git clone <ссылка на ваш репозиторий>
cd app
git checkout claude/macos-app-development-azxeq5
```

## Шаг 3. Создайте проект в Xcode

Готовый `.xcodeproj` из этого окружения не поставляется (его нельзя надёжно проверить без macOS), поэтому проект создаётся штатным мастером Xcode — это займёт одну минуту:

1. Откройте Xcode → **File → New → Project…**
2. Выберите вкладку **macOS**, тип **App**, нажмите **Next**.
3. Заполните:
   - Product Name: `HabitTracker`
   - Interface: **SwiftUI**
   - Language: **Swift**
4. Сохраните проект в удобное место (например, рядом с папкой `app`, которую вы склонировали).
5. Xcode создаст файлы `HabitTrackerApp.swift` и `ContentView.swift` — **удалите их** (в панели слева, правый клик → Delete → Move to Trash), они будут заменены на код из репозитория.
6. В панели слева правый клик по группе `HabitTracker` → **Add Files to "HabitTracker"…** → выберите все файлы и папки `Models` и `Views` из склонированного репозитория (`app/HabitTracker/...`), а также `HabitTrackerApp.swift`. Убедитесь, что стоит галочка **Copy items if needed**.

## Шаг 4. Запустите

Нажмите **▶ (Run)** или `Cmd+R`. Через несколько секунд откроется окно приложения с двумя вкладками:

- **«Мои привычки»** — работает сразу, без сервера, данные хранятся только на этом Mac.
- **«Дашборд»** — покажет данные участников из Telegram-бота, но только после того, как вы запустите и настроите сервер (см. [`server/README.md`](server/README.md)) и впишете его адрес и токен в настройках вкладки (значок шестерёнки).

## Как продолжать «вайбкодить»

Дальше работа строится так: вы описываете, что хотите изменить или добавить, а я пишу код и кладу файлы сюда же, в ветку `claude/macos-app-development-azxeq5`. Вам останется подтянуть изменения (`git pull`) и нажать Run в Xcode.

Идеи для следующих шагов:
- Иконка приложения и красивый значок в Dock
- Виджет со статистикой на сегодня
- Уведомления-напоминания в течение дня
- Календарь-«тепловая карта» выполнения по месяцам
- Синхронизация между устройствами через iCloud
