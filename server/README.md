# HabitTracker — сервер (Telegram-бот + API)

Небольшой сервер на Node.js, который:

- принимает от участников числовые показатели через Telegram-бота;
- хранит всё в файле SQLite (`data/habits.sqlite`);
- отдаёт сводные данные по HTTP для дашборда в Mac-приложении.

## Как это работает

1. Участник пишет боту `/start` и выбирает свою **группу**. Сменить её можно потом в «⚙️ Настройки».
2. Бот показывает **пункты группы** (чтение, спорт…). На каждой кнопке виден прогресс недели, например `🟡 BOOK · 84/150 стр.`:
   - пункт типа **«Число»**: нажмите на него и отправьте число, например `21`. Отметки складываются, и бот отвечает «За неделю: 84 из 150, осталось 66»;
   - пункт типа **«Отметка»** (⬜/✅) отмечает день одним нажатием, повторное нажатие снимает отметку;
   - для пунктов вроде баллов теста можно выбрать подсчёт **«лучший»**: тогда в зачёт недели идёт лучший результат, а не сумма.
3. Под пунктами выбирается, **за что** вносится значение: **Сегодня**, **Вчера**, **Неделя** (итог сразу за всю неделю) или **📅 Другое** (любой прошлый день в календаре или прошлая неделя целиком). Можно отмечать каждый день, раз в неделю или сочетать оба способа.
4. «↩️ Отменить последнюю отметку» удаляет последнюю внесённую отметку, если ошиблись.
5. **Вечером** (по умолчанию в 21:00) бот сам спрашивает, что сделано сегодня, и присылает кнопки для отметки, в том числе за вчера. **В воскресенье** (по умолчанию в 21:30) он присылает итоги недели: что выполнено и место в группе. Участник может выключить напоминания в «⚙️ Настройки». Команды: `/menu` открывает кнопки, `/week` показывает прогресс недели.
6. В разделе **🧍 Личные** участник добавляет свои пункты с недельной целью. Они приватные и в общий дашборд не попадают.

Цели задаются **на неделю** (пн–вс). Пункт 🟢 зелёный, если цель недели набрана, 🟡/🔴 — если что-то внесено, но меньше цели, ⚪ — если ничего нет.

### Группы и пункты

Группы, пункты, недельные цели и время напоминаний хранятся в файле `data/config.json`, а не в коде. При первом запуске он создаётся из `config.default.json`. Редактировать его удобнее всего в Mac-приложении: кнопка «Группы и пункты» на вкладке «Дашборд». Можно и вручную в текстовом редакторе: сервер подхватит изменения без перезапуска.

У каждой группы и каждого пункта есть `key`. По нему отметки участника связаны с пунктом, поэтому пункт можно переименовать без потери истории. Если удалить пункт, отметки остаются в базе и вернутся, если добавить пункт с тем же ключом. Если удалить группу, её участники выберут группу заново при следующем нажатии в боте.

### Дашборд в Mac-приложении

Вкладка «Дашборд» показывает пункты выбранной группы: процент выполненных целей у каждого участника. Масштаб выбирается сверху, стрелками ‹ › можно листать назад:
- **День**: цель недели делится на 7, то есть это «идёт ли человек в темпе»;
- **Неделя** (пн–вс): карточки с суммой по каждому пункту против цели;
- **Месяц**: тренд по неделям месяца.

Клик по участнику открывает его карточку: отметки за период и столбики по неделям против цели.

Отметка «за неделю» распределяется по дням недели поровну, поэтому в дневном виде видна её седьмая часть.

При переходе на суммы (эта версия) база сначала копируется в `data/habits.backup-before-sums-….sqlite`. Из старых значений, внесённых повторно за один и тот же период, остаётся только последнее, как это и работало раньше.

## Шаг 1. Создайте бота и получите токен

1. В Telegram напишите **@BotFather**.
2. Отправьте `/newbot`, придумайте имя и username (должен заканчиваться на `bot`).
3. BotFather пришлёт токен вида `123456789:AAExample...` — сохраните его, он понадобится ниже.

## Шаг 2. Запустите сервер на своём Mac

Нужен установленный [Node.js](https://nodejs.org) — скачайте LTS-версию с сайта и поставьте как обычное приложение.

Откройте **Terminal** (Программы → Утилиты → Terminal) и выполните:

```bash
cd путь/до/склонированного/репозитория/app/server
npm install
cp .env.example .env
```

Откройте файл `.env` любым текстовым редактором (например, `open -e .env` откроет его в TextEdit) и впишите:
- `BOT_TOKEN` — токен от BotFather
- `API_TOKEN` — придумайте любую длинную случайную строку (это пароль, которым Mac-приложение будет подтверждать доступ к дашборду)

Запуск:

```bash
npm start
```

Если всё верно, увидите `API server listening on port 3000` и `Telegram bot started`. Напишите боту `/start` в Telegram — должен ответить.

**Важно:** бот работает только пока это окно Terminal открыто и команда `npm start` выполняется, и только пока сам Mac включён и не спит. Закрыли Terminal или Mac ушёл в сон — бот перестаёт отвечать. Чтобы бот работал круглосуточно, переходите на Railway (шаг 3).

## Шаг 3. Работа 24/7 на Railway

Локальный сервер работает, только пока Mac включён. Чтобы бот и дашборд работали круглосуточно, сервер разворачивается на [Railway](https://railway.com). Это платный сервис (порядка нескольких долларов в месяц, точные цены уточняйте на сайте).

1. Зарегистрируйтесь на railway.com через GitHub.
2. **New Project → Deploy from GitHub repo** и выберите этот репозиторий. Если Railway попросит доступ к репозиториям, разрешите.
3. Откройте созданный сервис → **Settings**:
   - **Source → Root Directory**: `server`;
   - **Source → Branch**: ветка, в которой лежит код (сейчас `claude/macos-app-development-azxeq5`).

   Railway сам найдёт `Dockerfile`.
4. **Variables** → добавьте:
   - `BOT_TOKEN` — токен от BotFather (тот же, что в `.env`);
   - `API_TOKEN` — тот же секрет, что в `.env`.

   `PORT` Railway задаёт сам. Часовой пояс по умолчанию `Asia/Almaty`, это время напоминаний. Если нужен другой, добавьте переменную `TZ`, например `Europe/Moscow`.
5. Правой кнопкой по сервису на схеме проекта (или ⌘K) → **Attach Volume**, **Mount path**: `/app/data`. Без диска база и `config.json` будут стираться при каждом перезапуске.
6. **Settings → Networking → Generate Domain**. Получится адрес вида `https://app-production-xxxx.up.railway.app`: это адрес сервера для Mac-приложения.
7. Дождитесь, пока деплой станет зелёным (**Deployments → View logs**). В логах должно быть `API server listening` и `Telegram bot started … time zone Asia/Almaty`.
8. **Остановите локальный сервер** (Ctrl+C в Terminal). У одного бота может быть только одно подключение: если оба сервера запущены, один из них упадёт с ошибкой `409 Conflict`.
9. В Mac-приложении откройте «Дашборд» → ⚙️ и впишите новый адрес и тот же API-токен.

В облаке сервер начинает с пустой базы: участники один раз пишут боту `/start` и выбирают группу. Группы и пункты создаются из `config.default.json`, поправить их можно в приложении («Группы и пункты»).

Новые изменения кода Railway разворачивает сам после каждого `git push` в выбранную ветку.

## Шаг 4. Настройте Mac-приложение

1. Откройте приложение, перейдите на вкладку **«Дашборд»**.
2. Нажмите значок шестерёнки.
3. Впишите адрес сервера:
   - при локальном запуске (шаг 2) — `http://localhost:3000`
   - при облачном деплое (шаг 3) — адрес вида `https://ваш-проект...`, без каких-либо `/api/...` в конце (само приложение допишет нужный путь)
   
   И тот же `API_TOKEN`, что в `.env` сервера.
4. Нажмите «Готово», затем кнопку обновления (значок ⟳) — если всё настроено верно, появится список участников.

## Безопасность

- `API_TOKEN` — единственная защита дашборда, не публикуйте его и не коммитьте `.env` в git (он уже добавлен в `.gitignore`).
- Данные участников (имя из Telegram и отметки о привычках) хранятся только на вашем сервере.
